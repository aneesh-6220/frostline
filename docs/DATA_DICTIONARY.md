# Data dictionary

All CSVs: UTF-8, comma-separated, header row, ISO dates, load with `pandas.read_csv`. Every derived file is regenerated by `python3 -I scripts/regenerate_all.py`. Raw inputs in `data/raw/` are never modified.

## Raw inputs (read only)
`data/raw/nasa/power_daily_T2M_{dettah_bay,aklavik_delta}.csv` (POWER daily T2M and PRECTOTCORR, 2001-10-01 to 2025-06-30); `power_daily_ext_<corridor>.csv` (9 corridors, 10 variables); `power_monthly_T2M_yellowknife_1993_2024.csv` (user-supplied monthly file, used only as a cross-check); `data/raw/roads/NWT_Table108_...xlsx`; `data/raw/weather_stations/eccc_*.csv`.

## Core tables
| File | Content |
|---|---|
| `road_operations.csv` | One row per route and winter (544 rows, 17 routes, 32 winters). Columns: road_id, season_start_year, opening_date, closing_date (only when `record_status` = verified), record_status (`verified` 512, `missing_not_available` 24, `not_applicable_note` 4, `flagged_inconsistent` 4), source_url, road_type, road_name, source_sheet, record_note |
| `locations.csv` | location_id, name, role, road_id, latitude, longitude, coord_basis, coord_source, nasa_grid_note, station_id, station_distance_km |
| `nasa_daily_temperature.csv` | location_id, date, temperature_c (empty = missing, never 0), source_id. 2001-10-01 to 2025-06-30, 8,674 days per location. Values are MERRA-2 reanalysis, not observations |
| `nasa_daily_precipitation.csv` | location_id, date, precip_mm_per_day, source_id |
| `nasa_daily_variables.csv` | extended 10-variable daily table for 9 corridors |
| `season_audit.csv` | coverage audit per location and winter (48 rows) |
| `season_metrics.csv` | location_id, season_start_year, fdd_octdec, thaw_days_janmar, longest_thaw_run_janmar, mean_octdec_c, mean_janmar_c, mean_full_c, fdd_pre_cutoff, mean_pre_cutoff_c, mean_mar15_preclose_c, open_day, close_day, open_to_close_days |
| `extended_season_metrics.csv` | 9 corridors x 24 winters, extended variables |
| `station_validation.csv`, `station_summary.csv`, `station_fdd_by_season.csv` | NASA vs ECCC Yellowknife A matched days and summaries |
| `station_validation_aklavik_inuvik.csv`, `station_summary_aklavik_inuvik.csv` | NASA vs ECCC Aklavik and Inuvik stations |
| `yellowknife_snow_by_season.csv` | snow predictors per winter (snowfall, snow on ground) with open_day |

## Statistics outputs
| File | Content |
|---|---|
| `trend_results.csv` | Theil-Sen per decade, CI, Mann-Kendall tau, z, p, lag-1, status (`ok`, `constant_series`, `mostly_tied`, `too_few`) for Dettah and Aklavik and sensitivity variants |
| `regional_comparison.csv` | difference-series trends (Dettah minus Aklavik) |
| `extended_trends.csv` | 126 trend tests (14 metrics x 9 corridors) |
| `multiple_testing_126.csv` | the same 126 tests with block-bootstrap CI, BH q (all 126 and within family), Holm, autocorrelation flag, modal fraction |
| `hypothesis_families.csv` | definition of families F1 to F5 and the correction used |
| `road_record_trends_all_routes.csv` | 51 road-date trend tests (17 routes x 3 metrics), full 1993-2024 record, with q and Holm (selection adjustment) |
| `headline_trend_sensitivity.csv` | Dettah and Aklavik road-date sensitivity variants |
| `road_climate_correlations.csv` | leak-free Spearman associations with block-bootstrap CI and family q |
| `analysis_windows.csv`, `leakage_audit.csv` | leakage-free window ends and the audit of the older windows |
| `snow_vs_opening.csv`, `snow_trends.csv` | snow predictors vs Dettah opening (5-test family, BH and Bonferroni) and trends of the snow series |
| `corridor_panel.csv` | per-corridor summary of trends (descriptive; p-values unadjusted) |
| `remediation_summary.json` | counts used by `docs/RESULTS.md` |
| `diagnostics/` | NASA vs station bias diagnostics (`diagnostics_summary.json`, monthly and era tables, lag test, worst days) |

## Removed files
`pooled_anomaly_correlations.csv` was removed: pooling winters across corridors treats dependent series as independent. `mean_mar15_apr15_c` in `season_metrics.csv` was replaced by `mean_mar15_preclose_c` (leakage-free window).

## UI data
`UI/data_real/` is regenerated from `data/processed/` by `scripts/build_ui_data_real.py`. `UI/data/` is the legacy synthetic prototype dataset and must not be shown as real (`UI/README.md`).

## Interval caveat
`season_length_days` (UI) and `open_to_close_days` are the interval from opening to closing date, not usable days.
