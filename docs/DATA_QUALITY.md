# Data quality policy and audit

## 1. Missing-data policy (defined BEFORE any trend is computed)
- **Complete coverage is required** for any season entering FDD, thaw-count or seasonal-mean trends. Complete means every expected daily record exists exactly once with a valid number: 92 days Oct to Dec, 90 or 91 days Jan to Mar.
- A season with any missing, duplicate-conflicting or invalid day is flagged and excluded from the trend (its value is NaN). It is listed in the season audit table.
- Never fill a missing day with 0 degrees C, a neighbour, an average or an interpolation. Never add up the available days and call it a seasonal total.
- Invalid values: sentinel codes (NASA POWER uses -999; MERRA-2 files use 1e15 fill values) and anything outside -70 to +45 degree-C are treated as missing.
- Duplicates: a date that appears more than once is flagged; the season is not complete until the duplicate is resolved by going back to the raw source (not by choosing one).
- If a chosen period has substantial gaps, choose a better-covered period and document the change (do not manufacture continuity).
- A different rule (for example, allow up to 1 missing day by interpolation) needs written approval from Yao and a sensitivity run with and without it.

## 4. Validation data (ECCC station)
Obtained for Dettah: ECCC Yellowknife A daily mean temperature, 2001 to 2025, about 6 km from `dettah_bay`. The station ID changes in 2013 (1706 to 2012, 51058 from 2013; Climate IDs 2204100/2204101); the NASA-minus-station bias is the same before and after (-2.25 vs -2.26 C). Station gaps in Oct-Mar: 2012 (16 days), 2013 (3), 2016 (2), 2017 (3), 2018 (1), 2019 (4), 2020 (1), 2021 (3), 2022 (1), so only 17 winters have complete station FDD. `station_validation.csv` and `station_summary.csv` are created. No Aklavik station has been checked.

## 5. What a reviewer should check first
1. `road_operations.csv`: dates are ISO, only `verified` rows have dates.
2. After the NASA download: run the audit script; confirm every included season has 92 + 90/91 valid days.
3. Kelvin to Celsius done exactly once.
